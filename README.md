# Windows Server & Active Directory Lab

A practical home lab documenting Windows Server administration,
Active Directory, Hyper-V virtualization, iSCSI storage and
Failover Clustering.

## Lab Environment

| Server | Role |
|---|---|
| DC01 | Domain Controller |
| NODE01 | Hyper-V Node 1 |
| NODE02 | Hyper-V Node 2 |
| STORAGE01 | iSCSI Storage Server |

## Technologies

- Windows Server 2019 / 2022
- Active Directory Domain Services
- DNS and DHCP
- Group Policy
- Microsoft Hyper-V
- Windows Failover Clustering
- iSCSI Storage
- PowerShell

## Repository Structure

- docs/architecture - Infrastructure diagrams
- docs/build-guides - Installation and configuration
- docs/operations - Administration procedures
- docs/troubleshooting - Issues and solutions
- scripts - PowerShell automation
- screenshots - Sanitized lab screenshots

## Project Status

Documentation and lab validation in progress.

## Security

This repository is intended for a personal learning lab.
No passwords, credentials, private keys or confidential
production infrastructure information should be published.
